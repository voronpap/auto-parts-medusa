# Сервіс парсерів

Шукає номер деталі в каталогах виробників і передає каталогу магазину те, що
ці каталоги кажуть: аналоги, застосовність і характеристики.

Сервіс працює за запитом. Він забирає завдання з каталогу, проганяє номер по
джерелах і надсилає результат. Каталог до сервісу не звертається. Формат
обміну описано в [`docs/LOOKUP_FORMAT.md`](../../docs/LOOKUP_FORMAT.md).

## Правила, яких дотримується кожен адаптер

- Передає лише те, що сказало джерело. Не виводить кроси зі схожості номерів
  і не робить деталі взаємозамінними через спільну застосовність.
- Номери — точно як у джерелі, з пробілами, дефісами, нулями й суфіксами.
- Дослівне формулювання джерела зберігається в `raw_relation_text` і `raw_text`.
- Вердикт «підходить / не підходить» не ставить: це вирішує каталог.
- Номер, знайдений під іншим брендом, збігом не вважається.
- Якщо джерело має API, адаптер працює через нього; розбір HTML — запасний
  варіант.
- Вхід, captcha й захист від ботів не обходяться. Таке джерело повертає помилку
  `SourceBlocked` і пропускається.

## Як сервіс поводиться з джерелами

- представляється в заголовку `User-Agent` і дає адресу сайту;
- тримає паузу між запитами до одного хоста (типово 5 секунд);
- кешує відповіді на тиждень, щоб не питати те саме двічі;
- збій одного джерела не зупиняє решту й потрапляє в `errors` результату.

## Встановлення

    cd apps/parsers
    python3 -m venv .venv
    .venv/bin/pip install -e ".[dev]"
    .venv/bin/pytest

## Команди

    .venv/bin/python -m parsers adapters
    .venv/bin/python -m parsers lookup --brand Bosch --number "0 986 478 123"
    .venv/bin/python -m parsers run

`lookup` друкує результат і нічого нікуди не надсилає — так перевіряють
адаптер. `run` працює постійно: забирає завдання й надсилає результати.

## Налаштування

Змінні середовища для `run`:

| Змінна | Зміст |
|---|---|
| `CATALOG_URL` | адреса магазину, наприклад `http://127.0.0.1:9000` |
| `CATALOG_API_KEY` | секретний API-ключ Medusa |
| `PARSERS_WORKER` | назва цього екземпляра в журналі завдань |
| `PARSERS_CACHE` | шлях до файлу кешу відповідей |

Ключ береться лише зі змінної середовища. Його немає в аргументах команд,
коді, логах і репозиторії.

## Як додати джерело

1. Знайти, як каталог віддає дані. Спершу — чи його сторінка звертається до
   JSON API (видно в мережевих запитах браузера); якщо так, використовувати його.
2. Створити клас у `parsers/adapters/`, успадкований від `Adapter`:
   `source` (назва має збігатися з реєстром джерел каталогу), `brands`, `lookup`.
3. Зберегти кілька реальних відповідей джерела в `tests/fixtures/` і написати
   тести без мережі: збереження нулів і роздільників, напрямок `SUPERSEDED_BY`,
   номер під іншим брендом, часткові дані застосовності.
4. Додати клас у `ADAPTERS` у `parsers/adapters/__init__.py`.
5. Перевірити командою `lookup` на реальному номері.
6. Будь-яка зміна логіки розбору — нова `version` адаптера.
